# NEXUS Messenger

Версия без `better-sqlite3`, Python и сборки нативных модулей. Использует JSON-файл `nexus-data.json` для хранения аккаунтов и сообщений.

## Запуск на Windows
1. Распакуй архив в обычную папку, например `C:\NEXUS` (лучше не в OneDrive).
2. Открой PowerShell в этой папке.
3. Выполни `npm.cmd install`.
4. Запусти `npm.cmd start`.
5. Открой http://localhost:3000 и создай аккаунт.

Если хочешь, чтобы другие пользователи подключались через интернет, сервер нужно отдельно разместить на хостинге/VPS, настроить HTTPS и задать надёжный `JWT_SECRET`. Это стартовый проект: перед публичным запуском нужны дополнительные проверки доступа к личным комнатам, защита от спама, восстановление аккаунта и другие меры безопасности. JSON-хранилище подходит для небольшого теста, не для большой нагрузки.
